# 0011 — Дизайн терминала: «Имперский телекс + QoL»

## Намерение и зачем

Терминал читают персонажи кампании из мира Британской Империи 2061 года, но реальные
пользователи — игроки 2026 года с компьютера и телефона. Текущий дизайн (зелёный
фосфор CRT) аутентичен, но не работает на «Британскую Империю» и не даёт современного
удобства (поиск, фильтры, сортировка, понятные состояния).

Направление выбрано владельцем по серии мокапов (`mockups/01…06`): **«02 внешне +
04 внутри»** для публичной части, **«06»** для админки. Мокапы остаются в репозитории
как визуальный референс до конца реализации.

Принцип: **функционал 2026 — лицо 1985**. Никаких анимаций и декоративных эффектов;
выразительные средства — только цвет, рамки, сетка, типографика.

## Цели

- Публичная часть и админка в едином канцелярском стиле: шапка Адмиралтейства,
  латунь/пергамент/сургуч, документы как «бумага».
- Современный UX: живой поиск с подсветкой, фильтры-чипы, сортировка, счётчики
  результатов, хлебные крошки, связанные материалы, понятные пустые состояния.
- Работоспособность с телефона (390px): нижняя таб-панель навигации, тач-таргеты.
- Активное использование установленного Reka UI (компоненты перечислены ниже).

## Не-цели

- Изменение домена пакетов, импорта, форматов контента.
- Изменение 3D-сцены карты (`StarScene.client.vue`) — только оформление вокруг неё.
- Новые зависимости (кроме того, что уже в `package.json`).

## Анти-цели

- Анимации «красоты», свечения, scanlines, glassmorphism — стиль строгой канцелярии.
- Поломка e2e-тестов: селекторы и пользовательские сценарии должны продолжить работать
  (при необходимости — обновить тесты в рамках этого же плана, не отключать).
- Иконки-эмодзи в продакшен-шаблонах (вензель — inline-SVG, см. решения ниже).

## Ограничения

- Biome для всех файлов, включая шаблоны Vue; `npm run format`, `npm run check`.
- Vue-шаблоны декларативны; логика — в именованных функциях скрипта (AGENTS.md).
- Все тексты через i18n (`i18n/locales/ru.json`); новые строки — только туда.
- Reka UI 2.11 уже установлен. **Табличного компонента в Reka UI нет** (проверено по
  составу пакета) — таблицы делаются семантическим `<table>` со стилями.
- Моноширинный шрифт уже подключён как «Icarus Terminal» (`--terminal-font`);
  антиква — системный стек Georgia/serif, без новых шрифтов.

## Подходы (рассмотренные)

1. «Фосфорный CRT» (мокап 01) — предельная аутентичность терминала. Отклонён:
   не работает на Империю, тяжеловат для телефона.
2. «Имперский телекс» (02) — канцелярский стиль. Взят как внешний слой.
3. «Корабельный мостик» (03) — современный UX со вкусом 80-х. Отклонён как база,
   но заимствована идея статус-чипов.
4. «QoL в ретро-обложке» (04) — функциональный слой. Взят внутрь 02.
5. Комбинация 02+04 (05) — утверждена владельцем. Админка — отдельный мокап 06,
   утверждён с правками (таблица дел, чипы одной ширины, дата последней колонкой).

## Решения (владелец + builder-check)

- **Дата статьи** (владелец): показываем **дату первого получения** — `receivedDate`
  пакета, которым статья впервые опубликована. Печать «ПОЛУЧЕНО», даты в списке
  архива и сортировка по дате используют её. Требует **добавочного** расширения
  публичного API: поле `receivedDate` в `ArchiveArticleSummaryDto` и `ArticleDetailDto`
  (заполняется на сервере минимальной датой published-пакета, изменившего статью).
- **Admin API** (владелец): разрешено маленькое добавочное расширение — `changeCount`
  в `PackageInfo` (для таблицы дел) и `source` в метаданных пакета (для редактора).
  Публичные контракты, кроме пункта выше, не меняются.
- **Вензель** (владелец): inline-SVG, один небольшой файл, единый вид на всех
  платформах.
- **Область поиска** (реality-чек): текущий поиск архива **уже ищет по полному телу
  статей** (`server/api/public/archive.get.ts`). Сохраняем как есть, серверный SQL не
  трогаем; фронт лишь оборачивает существующий `?q=` в живой поиск с подсветкой.
- **Оболочка админки** (решение автора дизайна, подтверждено мокапом 06): админские
  страницы получают собственный Nuxt layout со служебной шапкой («ICARUS — Канцелярия»,
  навигация: Дела / Импорт YAML / Выйти), публичная оболочка им не расширяется.

## Дизайн-токены (заменяют `:root` в `app/assets/css/main.css`)

- `--terminal-bg: #10151d` (чернила), `--terminal-panel: #1a2130`,
  `--terminal-paper: #ece3c8` (пергамент), `--terminal-ink: #22201a` (чернила на бумаге).
- Акценты: `--terminal-brass: #c9a227` (латунь/основной акцент),
  `--terminal-seal: #b0413e` (сургуч/ошибки/черновик),
  `--terminal-ok: #46c07a` (публикация/успех),
  `--terminal-dim: #8d8871`, `--terminal-faint: #6b6650`.
- Текст: `#d8d2bd`; бордюры: `#3a3423`, тонкие `#2a3140`.
- Шапка: двойная латунная линия (`border-bottom: 3px double`), inline-SVG вензель,
  министерство капсом с широким трекингом, «ICARUS» антиквой, строка корабля.
- Заголовки разделов — Georgia/serif капсом; тело — моноширинный.
- «Документ» (статья): пергаментный фон, тонкая внутренняя тень, печать «ПОЛУЧЕНО»
  с датой (rotated, двойная рамка сургучем), строка источника.

## Изменения по областям

### Публичная оболочка (`app.vue`, `main.css`)

- Шапка по мокапу 05: вензель-SVG, министерство, ICARUS, HMS Peregrine, навигация;
  активный раздел — инверсия латуни. Футер без изменений по составу.
- На ≤720px навигация уходит в нижнюю таб-панель (4 вкладки с подписями, таргеты
  ≥44px; вход остаётся в шапке мелким текстом).

### Главная (index.vue)

- Карточки служб: панели с латунной верхней кромкой, номер раздела («РАЗДЕЛ I»),
  антиква заголовка, стрелка «→».

### Архив (archive/index.vue и страница статьи)

- Панель инструментов: строка поиска (живой, серверный `?q=` как сейчас, подсветка
  `<mark>` совпадений в названии), select сортировки (дата / название / раздел),
  чипы фильтров по категориям, счётчик «Найдено: N».
- Пустое состояние: что не так и что попробовать.
- Страница статьи: крошки, печать с датой первого получения, строка источника,
  связанные материалы «См. также по реестру».

### Карта, пакеты, вход

- Карта: оформление тулбара/панелей в токены; 3D-канвас не трогаем.
- Пакеты: список как архив (номер, название, дата), журнал — «хроника».
- Вход: форма в канцелярской панели.

### Админка (собственный layout, index.vue, packages/[id].vue, import.vue)

- Служебная шапка: «ICARUS — Канцелярия», навигация Дела / Импорт YAML / Выйти;
  панели с серой кромкой (отличие от латунной публичной).
- Главная: «Приказ о кампании» (dirty-индикатор), дела — **семантическая таблица**
  с шапкой (Название / Изменения / Статус / Получен), статус-чипы фиксированной
  ширины (190px, центрированы), длинные названия — ellipsis; ≤720px таблица
  складывается в карточку. «Завести новое дело» — панель.
- Редактор: метаданные сеткой (включая источник); изменения с метками вида сущности
  и операции; проблемы валидации — «Замечания канцелярии»; публикация заблокирована
  при замечаниях с пояснением; подтверждения удаления/отмены публикации — AlertDialog
  вместо `window.confirm`.
- Импорт: сводка проверки счётчиками, зелёная строка «замечаний нет».

### Reka UI (точки внедрения)

- `Autocomplete` / `Combobox` — поиск архива (с подсветкой результатов).
- `Select` — сортировка архива и фильтр статусов дел.
- `Tabs` — если появятся вкладки (архив/карта секции).
- `AlertDialog` — подтверждения (удалить черновик, отменить публикацию, выход).
- `Toast` — обратная связь (сохранено, опубликовано, ошибки сети).
- `Tooltip` — пояснения кнопок с иконками.
- Таблицы дел — семантический `<table>` (в Reka UI таблицы нет).

## Доступность и мобильная версия

- Контраст латуни/пергамента/чернил проверен на читаемость; пергамент — только
  большие плоскости текста (документ), не мелкие элементы.
- Фокус-стили: латунная обводка, видимая на всех интерактивных элементах.
- Таб-панель на мобильном — с подписями, таргеты ≥44px.
