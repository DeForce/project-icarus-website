# 0013 — Terminal Font Anonymous Pro

Status: Implemented.
Date: 2026-11-05.

## Intent

Сделать терминал визуально более old-school, заменив фактически работающий
системный моноширинный стек (Consolas/Courier New) на веб-шрифт
**Anonymous Pro** с самостоятельным хостингом. Заголовки и антиква (Georgia)
не меняются. Имя «Icarus Terminal» в стеке сегодня — заглушка без файла
шрифта; эта спецификация закрывает и эту недосказанность.

## Scope and constraints

- Только моноширинный шрифт терминала (`--terminal-font` в
  `app/assets/css/main.css`). Серифные заголовки, цвета, вёрстка — вне scope.
- Жёсткое требование — полная кириллица: весь игроко-видимый текст русский.
- Лицензия Anonymous Pro — SIL OFL 1.1: самостоятельный хостинг и
  включение файлов в репозиторий разрешены; файл лицензии — в каталоге шрифта.
- Кириллица занимает больше места, чем латиница: проверить, что вёрстка
  (навигация, таблицы, кнопки) не ломается от переполнения.
- Интерфейс использует `° × « »` — все есть в Anonymous Pro; `→` (U+2192)
  в шрифте отсутствует и рендерится системным фолбэком (один глиф на странице
  карты, моноширинность выдерживается).

## Design

### Рассмотренные подходы

1. **Anonymous Pro (выбран)** — терминал 70-х, лёгкая OCR-«рваность»,
   сильный характер при сохранной читаемости; кириллица есть. Выбор
   пользователя после сравнения живых мокапов.
2. IBM Plex Mono — пишмашинный гротеск IBM Selectric; слишком «чистый»
   для задуманного вайба.
3. PT Mono — «наш» офисно-военный телетайп; компактный, но характер
   слабее Anonymous Pro.
4. Cousine (метрика Courier) — самый старый вид, но слишком широкий,
   теряет экономию ширины экрана.

### Решение

- Файлы шрифта (woff2, начертания 400 и 700, поднаборы cyrillic и latin;
  отдельного cyrillic-ext у Anonymous Pro нет — для русского текста не нужен)
  кладутся в `app/assets/fonts/anonymous-pro/` вместе с копией OFL-лицензии.
- `@font-face` — в `app/assets/css/main.css` (`font-display: swap`,
  локальные пути через `~assets` или относительные от CSS).
- Стек обновляется на:
  `"Anonymous Pro", "Consolas", "Lucida Console", "Courier New", monospace`.
- Мокапы в `mockups/` не трогаем (архивные артефакты дизайна 0011).

## Verification

- `npm run check` — зелёный (lint, typecheck, 87 unit, build; Vite эмитит
  четыре woff2 в dist, `url()` разрешаются).
- `npm run test:e2e` — 68 passed; один предсущий гидрационный флейк
  (`public-pages.spec.ts` «archive lists articles and supports search»,
  phone-проект под нагрузкой полного прогона) — не связан со шрифтом,
  изолированно 6/6.
- `tests/e2e/terminal-font.spec.ts` — 6/6 (desktop + phone): стек применён,
  начертания 400/700 реально загружаются (`document.fonts.load/check` с
  кириллическим образцом), Georgia у заголовков не изменилась, горизонтального
  переполнения нет на `/`, `/archive`, `/map`, `/packages`.
- Ограничение: `→` (U+2192) рендерится системным фолбэком — задокументировано
  в Design.
